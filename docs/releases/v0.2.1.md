# FlowWatch v0.2.1

> 发布日期：2026-08-19

## 本次更新

- Dashboard 底部新增持续显示的操作提示，新用户无需查阅文档即可知道如何切换页面、选择记录、查看详情、刷新和退出。
- Dashboard 支持用 `Esc` 关闭详情，当前页面标签在有颜色和无颜色终端中都更加明显。
- 趋势图改为连续折线，并显示明确的采样间隔、图例和缺失数据段。
- 应用排行移除冗余的同名程序合并说明；需要底层身份和路径时仍可使用 `--details`。
- `status` 输出改为明确区分实际流量、已找到应用的流量和未找到应用的流量，并显示统计时间范围。
- 异常时段统一使用易读的 `1分钟`、`5分钟` 等跨度格式。

## 常用入口

```sh
flowwatch dashboard --period 24h
flowwatch chart --period 24h
flowwatch status
flowwatch apps --period 24h
```

本版本继续不需要 `sudo`、Apple Developer 账号、系统扩展或内核扩展。

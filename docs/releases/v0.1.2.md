# FlowWatch v0.1.2

> 发布日期：2026-08-18

## 本次更新

- 修复中文终端中的表格对齐问题。
- `apps`、`interfaces`、`spikes` 和 `gaps` 现在按实际终端显示宽度对齐中文表头、数字和应用名称。
- 支持包含中文、全角字符或 emoji 的应用名称，不会因为字符宽度不同而挤乱数字列。
- 增加表格宽度回归测试，避免后续本地化改动再次破坏对齐。

## 升级

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/FlowWatch/main/scripts/install.sh | sh
```

升级会保留已有 SQLite 历史数据、Clash 设置、保存期限和应用明细精度。

# FlowWatch v0.2.2

> 发布日期：2026-08-19

## 本次更新

- 终端趋势图改用 Braille 高分辨率子像素绘制，每个字符可表达 2×4 个绘图点。
- 使用连续线段栅格化连接相邻采样点，上传、下载和合计不再显示为一串孤立的点。
- 自动为纵轴留出约 10% 的上边距，并提供更多坐标刻度，峰值和低流量变化更容易比较。
- 缺失采样时间段保持断线，不会把没有采集到的数据误连成一条线。
- CLI 和 Dashboard 共用同一套折线、坐标轴和缩放逻辑，两个入口的图形含义保持一致。
- 图例改为直接标注上传、下载、合计和交叠；无颜色终端也能看懂图例内容。

本版本继续不需要 `sudo`、Apple Developer 账号、系统扩展或内核扩展。

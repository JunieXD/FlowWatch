# FlowWatch v0.2.0

> 发布日期：2026-08-19

## 本次更新

- 每次应用排行都会同时显示 Mac 的实际流量、已经找到对应应用的流量、未找到应用的流量和识别率，结果是否完整一目了然。
- 新增 `flowwatch explain`，可分析指定时间或自动找到最高流量时段，并列出当时的主要应用、相邻时段变化和未找到应用的流量。
- 新增 `flowwatch app` 和应用趋势图，可查看单个应用的总量、来源、身份、路径、首次与最后出现时间以及流量最高时段。
- 新增 `flowwatch report`，一条命令汇总总量、主要应用、最高流量时段、数据完整度和异常提示，也可与上一段等长时间比较。
- 新增临时调查模式。需要排查短连接时可暂时切换到每秒采样和每分钟应用明细，到期、停止或重新启动后会自动恢复原设置。
- 新增每日、每月和单个应用的流量限额，可在达到 80% 和 100% 时发送 macOS 本机通知。
- 改进辅助进程和命令行程序的身份合并，并允许为不易理解的程序设置自己的显示名称，不会改写历史流量。
- 新增数据管理命令，可查看数据库范围与大小、导出 CSV 或 JSON、调整保存期限、清理旧记录和回收磁盘空间。
- 新增经过 SHA-256 校验的自更新命令，并支持通过 `brew install JunieXD/tap/flowwatch` 安装。
- 新增交互式 `flowwatch dashboard`，在一个终端界面中查看概览、趋势、应用排行和异常时段。

## 常用入口

```sh
flowwatch report --period 24h
flowwatch explain --period 24h
flowwatch app "ChatGPT" --period 7d
flowwatch dashboard --period 24h
```

不记得参数时运行 `flowwatch --help`；每个命令也可使用 `flowwatch <命令> --help` 查看中文说明和可直接运行的示例。

## 安装与升级

使用 Homebrew：

```sh
brew update
brew install JunieXD/tap/flowwatch
flowwatch install
```

已经安装 FlowWatch 时，也可以直接运行：

```sh
flowwatch update --check
flowwatch update
```

或者重新执行安装脚本：

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/FlowWatch/main/scripts/install.sh | sh
```

升级会保留已有 SQLite 历史数据、Clash 设置、应用名称、提醒规则、保存期限和采样设置。新功能不会默认提高后台采样频率；只有用户主动开启调查模式时，CPU 使用和应用明细量才会在指定时间内增加。

## 说明

FlowWatch 仍然不需要 `sudo`、Apple Developer 账号、系统扩展或内核扩展。应用统计来自定时采样，不能保证每一笔流量都找到对应应用；实际网卡总量始终独立保存，所有查询都会明确显示未找到应用的部分，不会猜测归属。

# FlowWatch v0.1.4

> 发布日期：2026-08-18

## 本次更新

- 新增 `flowwatch chart`，可直接在终端查看上传、下载和总流量趋势，不需要安装图形界面或额外依赖。
- 支持最近一段时间、指定日期和自定义起止时间，例如 `--period 6h`、`--date 2026-08-18` 或 `--from ... --to ...`。
- 趋势图会根据查询跨度和终端宽度自动选择合适的时间间隔，也可通过 `--interval`、`--width` 和 `--height` 手动调整。
- 上传、下载和合计使用不同颜色与符号显示；`--no-color` 可输出适合日志、重定向和纯文本环境的图表。
- 图表下方增加区间总量、最高流量时段和有效数据段数量，尚未结束的最后一个时间段会明确提示数值仍在增长。
- 所有流量查询命令新增 `--date YYYY-MM-DD`，可直接查看某个自然日，不再需要手动填写当天的开始和结束时间。
- 缺少采集记录的时间段会保持空白，不会显示成零流量；较早的数据会自动使用每日汇总，长期趋势仍可正常查看。

## 常用示例

```sh
flowwatch chart --period 6h
flowwatch chart --period 24h
flowwatch chart --date 2026-08-18
flowwatch chart --from "2026-08-18 09:00" --to "2026-08-18 18:00"
```

## 升级

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/FlowWatch/main/scripts/install.sh | sh
```

升级会保留已有 SQLite 历史数据、Clash 设置、保存期限和应用明细精度。本次更新不改变数据库格式，也不会增加后台采集的 CPU、内存或磁盘开销。

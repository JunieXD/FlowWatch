# FlowWatch v0.1.1

> 发布日期：2026-08-18

这是一次界面与文档本地化更新，不改变已有数据库格式、JSON 字段、命令名或参数名。

## 本次更新

- 默认 README、贡献指南、安全说明、架构说明、发布流程、Issue/PR 模板和 GitHub Actions 显示名称均改为简体中文。
- CLI 的正常输出、安装与卸载提示、诊断结果、设置显示、时间范围错误和采集错误改为简明中文。
- 将“归因”统一改为“应用识别”，将“覆盖率”改为“识别率”，并使用“带来源信息的连接”等说明替代内部术语。
- `--period` 新增 `今天`、`昨天`、`全部` 中文别名；原有 `today`、`yesterday`、`all`、`24h`、`7d` 等写法继续可用。
- `flowwatch apps` 对同名程序的合并说明改为“合并显示 N 个同名程序，来自 N 个路径”。
- 所有 JSON 字段和命令参数继续使用英文，避免影响脚本和已有自动化。

## 升级

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/FlowWatch/main/scripts/install.sh | sh
```

升级会保留已有 SQLite 历史数据、Clash 设置、保存期限和应用明细精度。

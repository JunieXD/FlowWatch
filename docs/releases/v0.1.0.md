# FlowWatch v0.1.0

> 发布日期：2026-08-18

FlowWatch 的第一个公开版本专注于一件事：在不需要管理员权限、内核扩展或 Apple Developer 签名的前提下，让 macOS 用户知道实际网络流量去了哪里，并诚实展示无法归因的部分。

## 主要功能

- 使用 macOS 原生 64 位网卡计数器维护物理上传、下载总账。
- 使用结构化 `nettop` 快照统计应用流量，并明确展示覆盖率和归因缺口。
- 可选连接 Clash Verge/Mihomo controller，识别代理后的应用流量并避免重复计算代理载体。
- 区分 Clash controller 总量、observed actor、已归因 actor 与非 actor/未观察流量。
- 提供应用排行、物理网卡、流量尖峰、归因缺口、JSON 输出和精确时间范围查询。
- 默认保存五分钟应用明细，可按需切换一分钟；默认保留 30 天明细和 365 天日汇总。
- 安装为当前用户的 LaunchAgent，登录后自动启动，不需要 `sudo`。

## 安装

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/FlowWatch/main/scripts/install.sh | sh
```

安装器会选择 Apple Silicon 或 Intel 版本，并在执行前校验 SHA-256。已有用户重复运行同一命令即可升级，现有数据库和自定义采集设置会保留。

## 已知边界

- 标准模式采用周期采样，完全发生在两次快照之间的短连接可能无法归因到应用，但仍会进入物理总账。
- Clash TUN/INNER、缺少进程身份的连接和采样边界流量会保留在未归因部分，不会被猜测分配给其他应用。
- 当前只支持 macOS 13 及更高版本；Windows 后端仍处于规划阶段。

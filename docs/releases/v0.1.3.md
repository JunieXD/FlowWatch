# FlowWatch v0.1.3

> 发布日期：2026-08-18

## 本次更新

- 重新设计命令行帮助。直接运行 `flowwatch` 或 `flowwatch --help`，即可看到首次使用步骤、常见任务和可直接执行的示例。
- 增加标准的 `flowwatch help <命令>` 用法，并为全部命令和配置子命令补充用途说明、参数规则与示例。
- 在 `apps`、`interfaces`、`spikes` 和 `gaps` 的帮助中明确说明自定义时间范围的写法、支持格式和起止边界。
- 改进命令行错误提示。现在会指出无法识别的命令或参数、缺少的值、冲突的选项和可用值，并在可能时给出正确写法。
- 安装完成、采集服务未运行或应用查询没有结果时，会显示建议执行的下一条命令。
- 增加相关回归测试，保证中文帮助、标准帮助子命令和常见错误提示持续可用。

## 升级

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/FlowWatch/main/scripts/install.sh | sh
```

升级会保留已有 SQLite 历史数据、Clash 设置、保存期限和应用明细精度。本次更新不改变数据库格式、JSON 字段、命令名或参数名。
